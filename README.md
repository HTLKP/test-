# 🎉 متجر المنتجات الرقمية - Digital Marketplace

موقع متجر منتجات رقمية احترافي مع تصميم حديث باللون الأصفر، مبني باستخدام HTML و CSS و JavaScript فقط.

## ✨ المميزات

✅ تصميم حديث وجذاب باللون الأصفر
✅ عرض منتجات في بطاقات احترافية
✅ نموذج تواصل يرسل البيانات إلى Discord webhook
✅ زر تواصل واتساب مباشر
✅ تصميم متجاوب مع الجوال والأجهزة اللوحية
✅ انيميشنات سلسة وتأثيرات احترافية
✅ لا يتطلب أي خادم أو قاعدة بيانات

## 📁 الملفات المتضمنة

- `index.html` - الهيكل الأساسي للموقع
- `styles.css` - التصاميم والألوان
- `script.js` - الوظائف والتفاعلات
- `README.md` - هذا الملف

## 🚀 الخطوات الأساسية للتشغيل

### 1️⃣ فتح الموقع
ببساطة افتح ملف `index.html` في متصفح الويب الخاص بك.

### 2️⃣ إعداد Discord Webhook (اختياري)

لتفادي الأخطاء، اتبع الخطوات التالية:

**أ) إنشاء Discord Server:**
- اذهب إلى https://discord.com
- أنشئ سيرفر جديد أو استخدم سيرفر موجود

**ب) إعداد الـ Webhook:**
1. اذهب إلى Server Settings → Webhooks
2. اضغط "Create Webhook"
3. أعطه اسماً (مثل: "ديجيتال ستور")
4. اختر القناة حيث يتم استقبال الرسائل
5. اضغط "Copy Webhook URL"

**ج) تحديث الكود:**
افتح ملف `script.js` وابحث عن:
```javascript
const DISCORD_WEBHOOK_URL = 'https://discordapp.com/api/webhooks/YOUR_WEBHOOK_ID/YOUR_WEBHOOK_TOKEN';
```

استبدل `YOUR_WEBHOOK_ID/YOUR_WEBHOOK_TOKEN` بـ URL الذي نسخته من Discord

### 3️⃣ إعداد رقم WhatsApp

افتح ملف `script.js` وابحث عن:
```javascript
const WHATSAPP_NUMBER = '966501234567'; // مثال: رقم سعودي
```

استبدل الرقم برقم WhatsApp الخاص بك:
- ضع كود الدولة بدون علامة +
- مثال للرقم السعودي: `966501234567`
- مثال للرقم المصري: `201001234567`

## 🎨 تخصيص الموقع

### تغيير الألوان
افتح `styles.css` وعدل المتغيرات في جزء `:root`:
```css
:root {
    --primary-color: #FFD700;      /* اللون الأساسي */
    --primary-dark: #FFC700;        /* اللون الداكن */
    --dark-color: #1a1a1a;         /* اللون الغامق */
    --light-color: #f5f5f5;        /* اللون الفاتح */
}
```

### إضافة منتجات جديدة
افتح `script.js` وابحث عن مصفوفة `products`:
```javascript
const products = [
    {
        id: 1,
        name: 'اسم المنتج',
        description: 'وصف المنتج',
        price: '29.99',
        emoji: '🎨'  // استخدم أي إيموجي
    },
    // أضف منتجات أخرى هنا
];
```

### تغيير اسم الموقع
ابحث عن العناصر التالية:
- في `index.html`: `<h1>💛 ديجيتال ستور</h1>`
- في `<title>`: `<title>ديجيتال ستور - متجر المنتجات الرقمية</title>`

## 💻 الاستخدام

### الميزات الرئيسية

**1. عرض المنتجات:**
- تظهر المنتجات تلقائياً عند تحميل الصفحة
- كل بطاقة تحتوي على اسم المنتج والسعر والوصف
- عند الضغط على "شراء الآن" يتم فتح WhatsApp مباشرة

**2. نموذج التواصل:**
- ملء البيانات المطلوبة (الاسم، البريد، الموضوع، الرسالة)
- الضغط على "إرسال الرسالة"
- سيتم إرسال الرسالة إلى Discord و عرض رسالة تأكيد

**3. أزرار التواصل:**
- زر WhatsApp: فتح محادثة مباشرة
- زر البريد الإلكتروني: فتح برنامج البريد الافتراضي

## 🐛 استكشاف الأخطاء

**المشكلة: رسائل التواصل لا تصل إلى Discord**
- الحل: تأكد من نسخ Webhook URL بشكل صحيح
- افتح Developer Console (F12) وتحقق من الأخطاء

**المشكلة: زر WhatsApp لا يعمل**
- الحل: تأكد من صحة رقم الهاتف بدون علامة +
- الرقم يجب أن يبدأ بكود الدولة (مثل 966 للسعودية)

**المشكلة: التصميم غير صحيح على الجوال**
- الحل: تأكد من وجود Meta tag: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
